# Пояснювальна записка — матеріали та збирання

Канонічний редагований документ: `coursework.docx`. Фінальний `coursework.pdf` створюється прямим експортом цього DOCX через LibreOffice. Markdown `coursework.md` збережено як джерело тексту; його статична таблиця змісту для читання в Markdown автоматично замінюється на поле змісту Word у DOCX. Чотири типи діаграм мають редаговані джерела й експортовані зображення в `diagrams/`.

## Відтворення

Із кореня проєкту запустіть:

```sh
python3 docs/report/tools/build_report.py
```

Потрібні Python 3 із системним UNO-модулем LibreOffice, Pillow, Matplotlib, Graphviz (`dot`) і LibreOffice. Скрипт перемальовує діаграми, створює DOCX, запускає LibreOffice без X display з VCL-плагіном `svp` та ізольованим профілем, оновлює TOC/PAGE/NUMPAGES поля, зберігає DOCX і експортує з нього PDF. Також виконується перевірка сторінок і записується `evidence/final-pagination-report.txt`.

Якщо DOCX відредаговано без зміни Markdown і потрібно лише оновити автоматичний зміст та PDF:

```sh
python3 docs/report/tools/finalize_docx.py
```

Поточний експорт: 34 сторінки A4; основна частина — 24 сторінки (стор. 5–28), що відповідає межі 16–32 сторінки. На стор. 6 і 12 залишаються короткі продовження попереднього тексту; порожніх сторінок немає. PDF — реальний експорт канонічного DOCX, не окремий Markdown-рендер.

## Перед остаточним поданням

- **SCREENSHOT_PENDING:** файла `screenshots/application-run.png` немає. Видимий заповнювач не є доказом запуску й має бути замінений справжнім знімком роботи програми.
- Заповнити поля студента, групи, номера залікової книжки, керівника, календарного плану, підписів і дат за офіційними документами.
- Отримати підтвердження керівника щодо повної площі поверхні, правого кругового конуса/циліндра, координатної моделі загального тетраедра й порогу виродженості `1e-12`.
- Перед друком повторно переглянути документ у цільовій версії Microsoft Word або LibreOffice. PDF нині зібрано й перевірено в LibreOffice; метрики Times New Roman у середовищі відображалися сумісним шрифтом Liberation Serif.

Звіт про фінальну пагінацію та перевірки: `evidence/final-pagination-report.txt`. Знімки сторінок не підмінялися штучно згенерованими зображеннями. Підписи, погодження й академічні результати не вигадувалися.
