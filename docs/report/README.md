# Пояснювальна записка — матеріали та збирання

Канонічний редагований документ: `coursework.docx`. Фінальний `coursework.pdf` створюється прямим експортом цього DOCX через LibreOffice. Markdown `coursework.md` збережено як джерело тексту; його статична таблиця змісту для читання в Markdown автоматично замінюється на поле змісту Word у DOCX. Чотири типи діаграм мають редаговані джерела й експортовані зображення в `diagrams/`.

## Відтворення

Із кореня проєкту запустіть:

```sh
python3 docs/report/tools/build_report.py
```

Потрібні Python 3 із системним UNO-модулем LibreOffice, Pillow, Matplotlib, Graphviz (`dot`) і LibreOffice. Скрипт перемальовує діаграми, створює DOCX, запускає LibreOffice без X display з VCL-плагіном `svp` та ізольованим профілем, оновлює TOC/PAGE/NUMPAGES поля, зберігає DOCX і експортує з нього PDF. Також виконується перевірка сторінок і записується `evidence/final-pagination-report.txt`.

Якщо DOCX відредаговано без зміни Markdown і потрібно лише оновити автоматичний зміст та PDF:

```sh
python3 docs/report/tools/finalize_docx.py
```

Поточний експорт: 31 сторінка A4; основна частина — 21 сторінка (стор. 6–26), що відповідає межі 16–32 сторінок. Діаграму класів збільшено до ширини текстового блоку; рисунок 2.1 розміщено на сторінці 12. Порожніх PDF-сторінок і коротких самостійних продовжень немає. PDF — реальний експорт канонічного DOCX, не окремий Markdown-рендер.
